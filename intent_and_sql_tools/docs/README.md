# intent_and_sql_tools

Minimal Brain + Hands + Registry Data Agent SDK scaffold for VeADK/Google ADK.

## Quick Start

```bash
python intent_and_sql_tools/entrypoints/train.py all
python intent_and_sql_tools/entrypoints/app.py
```

## Structure

- intent_tool/: intent training and tool entry
- data_agent_tool/: SQL training and tool entry
- common/: shared registry and Vanna base
- entrypoints/: app and train entry
- examples/: demo scripts
- config/: runtime config
