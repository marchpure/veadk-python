# Semantic design contract

- Treat the page as a modeling workbench: entity cards, field catalog and a
  relationship/evidence inspector.
- Use role colors only for entity, dimension, measure and time; never encode
  meaning by color alone.
- Keep source lineage and schema URI visible in the header or side rail.
- MDL is a disclosure element, not the primary page surface.
- Relationship rows use an explicit arrow and evidence locator.
