# Dashboard design contract

- Neutral canvas, white surfaces, one blue action accent, restrained borders.
- Use a clear title/source header, four-column KPI rhythm, two-column charts,
  then a wide evidence table.
- Numeric values are high contrast and tabular; labels are quiet and compact.
- SVG charts have fixed viewBox geometry and text labels; no canvas or runtime
  JavaScript is permitted.
- Filters, drill-downs and refresh are controls with visible focus states.
- At 900px switch to one-column modules; at 520px reduce padding and KPI scale.
- Empty, partial and stale data states remain explicit rather than hidden.
