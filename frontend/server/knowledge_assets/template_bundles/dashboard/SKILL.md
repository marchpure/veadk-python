# Dashboard Skill HTML bundle

Use this bundle when the typed ViewModel contains KPI, dimensional series and
row-level evidence. Choose the chart modules from the available series; never
invent a label, value, insight or source. Filters and drill-downs are emitted
as declarative artifact events for the Studio Shell.

The compiler owns layout and SVG geometry. The Agent owns only the internal
PresentationRecipe: information priority, density and which existing series
are visible.
